# ShopHub Storefront

Responsive customer-facing e-commerce app built with React, Vite, TypeScript, Tailwind CSS, pnpm and shadcn-style Radix primitives.

## Run

```bash
pnpm install
pnpm dev
```

## Screens

Home, shop/category listing, product details, cart, checkout, payment, order review, confirmation, orders, order details/tracking, wishlist, profile, addresses, payment methods, sign in, registration, about, contact, FAQ, shipping, returns, terms, privacy and responsive mobile navigation. Dialogs include newsletter, add-to-cart confirmation, remove-cart confirmation, address and card forms.
